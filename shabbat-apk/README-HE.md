# שעון שבת – אפליקציית אנדרואיד

## איך מקבלים APK (בלי להתקין כלום, בחינם)
1. נכנסים ל-github.com, יוצרים חשבון (אם אין), ולוחצים New repository (למשל `shabbat-clock`).
2. לוחצים Add file > Upload files, וגוררים פנימה את **כל התיקיות והקבצים** מתוך התיקייה שחולצה מה-ZIP (כולל התיקייה הנסתרת `.github`).
3. לוחצים Commit changes.
4. נכנסים ללשונית **Actions**. הבנייה מתחילה לבד ולוקחת כ-5 דקות.
5. כשהיא מסתיימת (וי ירוק), נכנסים אליה ובתחתית העמוד מורידים **shabbat-clock-apk**. בתוכו הקובץ app-debug.apk.
6. מעבירים לטאבלט ומתקינים (צריך לאשר "התקנה ממקורות לא ידועים").

## אחרי ההתקנה (חובה, פעם אחת)
- לאשר התראות ומיקום.
- לאשר "ללא הגבלת סוללה" כשהמסך הזה קופץ.
- באנדרואיד 14 ומעלה: לאשר "התראות במסך מלא".
- להיכנס להגדרות השעון, **להעלות את השירים והצפירה כקבצים מהמכשיר**, ולחכות כמה שניות.
- אחרי ההעלאה להפעיל "בדיקה" ולוודא שיש צליל, ואז לכבות את המסך ולהריץ בדיקה נוספת.

## מה עובד ואיך
- כל אירוע (תזכורות, שיר כניסה, צפירה, שירי מוצ"ש, ערב חג) נרשם כהתראת שעון מעורר של אנדרואיד, שעובדת גם כשהמסך כבוי והמכשיר ישן.
- בזמן האירוע שירות ברקע מנגן את הקול ומדליק את המסך.
- אחרי כל שבת האפליקציה מתעוררת לבד, מושכת זמנים חדשים ורושמת את האירועים הבאים.
- יוטיוב לא מנגן כשהמסך כבוי, רק קבצים שהועלו.
- בסרגל ההתראות יופיע סמל שעון מעורר. זה תקין.
